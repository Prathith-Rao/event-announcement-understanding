# Evaluation definitions

Version-2 addendum: classification uses 19 event categories plus an internal Not an event class. The older five-class results are historical. The hybrid_context row evaluates final context interpretation as well as the trained model, and is separate from standalone classifier results. Version-2 extraction's missing-field metric also accepts an explicit missing/ambiguous field_status intimation. Same-month explicitly stated date ranges may normalize to ISO start/end intervals. Rules and hybrid share context/classification and normalization; hybrid adds NLTK/CRF candidates. Full version-2 predictions and field supports are saved. The old final challenge remains frozen.

Classification uses five fixed target classes, macro precision/recall/F1 with zero division set to zero, accuracy, class supports, and a confusion matrix with an explicit ABSTAIN column. Abstentions count as errors, never disappear from the denominator. Unsupported classes have support zero; report them rather than calling all-class macro scores representative. The majority baseline uses the most frequent training label; ties follow training record order. Keyword ties abstain. NB features are binary lemma presence; logistic features are sublinear TF-IDF word unigrams/bigrams. This comparison changes representations as well as algorithms.

Extraction compares rules and hybrid on the identical examples, reference dates, and deterministic normalization. A correct present value is TP. A wrong non-null value counts as FP and, if a gold value exists, FN. A missing prediction for a present gold value is FN. A prediction for absent gold is FP. Both null is a correct absence, not TP. Precision = TP/(TP+FP); recall = TP/(TP+FN); F1 = 2PR/(P+R). Zero denominators yield zero. Field exact match includes absent gold and divides by all examples. This can be inflated when many fields are absent, so present-gold support and missing-field accuracy are also reported.

Raw exact match requires identical source substrings, including case and punctuation. Normalized exact match collapses whitespace/case for non-date values. Dates compare equal when both raw strings normalize to the same full ISO date using the same supplied reference date. Otherwise their raw strings are compared after case/whitespace normalization. A null normalized value is never itself evidence of equality; raw dates still matter. Human-supplied normalization is retained for audit but evaluation recomputes the documented normalization consistently. Date ranges outside implemented support remain missing with warnings.

Complete-record accuracy requires all four extraction fields to match; category is evaluated separately. A raw complete-record measure is also saved. Missing warning accuracy measures gold-null fields that remain null with a missing/ambiguity/range warning. Ambiguity warning accuracy requires specific codes for fixtures tagged multiple dates/times, category overlap, multiple events, ambiguous numeric date, and relative date without reference. Unsupported-detection accuracy compares whether each fixture should abstain from single-event extraction. These fixture handling metrics measure the annotated behaviors, not a calibrated confidence.

Development extraction fixtures can guide debugging. The reserved final synthetic challenge is evaluated explicitly once after the rules are frozen; it is never loaded by development evaluation. Its expectations were authored with automated assistance and require a separate human audit. Reviewed real extraction uses the same real final test rows as classification. No real extraction scores are claimed before those field annotations exist.

Interpret tiny synthetic tests as software and scenario checks. They cannot establish real-world accuracy, statistical significance, or superiority to another team. Report score deltas for preprocessing and chunking honestly, including zero improvements and regressions.
